## Installation
- Download latest `GiftCodeRedeemer.zip` archive from [release page](https://github.com/dm1tz/GiftCodeRedeemer/releases/latest).
- Extract archive contents into ASF `plugins` directory.

## Commands
Command | Alias | Access | Description
--- | ---| --- | ---
`redeemgiftcode [Bot] <giftCode> <redeemer>` | `rgc` | `Master`| Redeems Steam gift code for given bot.
`gcrversion` | `gcrv` | `FamilySharing`| Prints plugin version.
